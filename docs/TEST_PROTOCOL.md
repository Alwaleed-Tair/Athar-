# بروتوكول اختبار أثر (ATHAR) - محلي

كيف تستخدمه: نفّذ كل خطوة **بالترتيب**، وقارن بـ «المتوقع». سجّل في عمود النتيجة: ✅ مطابق / ❌ مختلف (واكتب ما ظهر فعلاً) / ⏭ تخطيت.
أي ❌ أرسله لي برقمه + ما ظهر + نص نافذة الأوامر (PowerShell) إن وُجد + لقطة شاشة إن أمكن.

---
## 0) تجهيز بيئة نظيفة (إلزامي ليكون التقييم دقيقاً)

1. أغلق الخادم إن كان يعمل (Ctrl+C في نافذته).
2. احذف البيانات القديمة (يضمن أن رقم أول قضية = 1):
   ```powershell
   cd C:\Users\wtair\Athar-
   git pull
   Remove-Item -Recurse -Force backend\storage -ErrorAction SilentlyContinue
   ```
3. تأكد من `backend\.env`: فيه `ATHAR_ADMIN_PASSWORD=Adm1n!Local#2026` و`ATHAR_MAIL_CONSOLE=1`، ولا يوجد `ATHAR_AI_KEY` ولا `ATHAR_SMTP_HOST` (الاختبار الأساسي بدونهما).
4. شغّل: `python run.py` ← يجب أن ترى `Uvicorn running on http://127.0.0.1:8000`.
5. افتح المتصفح (Chrome) على http://localhost:8000 ثم اضغط **F12 ← تبويب Console** وابقه مفتوحاً طوال الاختبار.
   - المتوقع في Console: لا أخطاء حمراء، عدا أخطاء 401/403/404/429 التي تنتج عن خطوات سلبية مقصودة (سأذكرها).
